Welcome to the **Web Development Challenge**! This is your opportunity to showcase your design skills and coding capabilities. You will build a highly responsive, modern web application from scratch.

### Rules
* **Team Size**: Maximum of 3 members per team.
* **Tech Stack**: Open to React, Vue, HTML/CSS/JS, or any modern framework.
* **Code Integrity**: All work must be completed during the event window. No pre-coded projects.
* **Deployment**: The final application must be deployed publicly (Vercel, Netlify, GitHub Pages, etc.).
* **Evaluation**: Judging will be based on responsive UI design (50%), code quality (30%), and functionality (20%).
