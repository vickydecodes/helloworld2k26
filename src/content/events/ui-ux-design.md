Design a premium, intuitive user interface for a real-world problem statement. Focus on user experience flow, visual harmony, accessibility, and micro-interactions.

### Rules
* **Team Size**: Individual or teams of 2.
* **Design Tools**: Figma, Adobe XD, or Sketch.
* **Deliverables**: A clickable, interactive prototype link and a brief case study slide.
* **Problem Statement**: Released exactly at the start of the event.
* **Evaluation**: Based on empathy/user flow (40%), UI aesthetics and visual system (40%), and prototype interactivity (20%).
